# Análisis de Ventas – Empresa Aliada

## Descripción

Este repositorio reúne los proyectos desarrollados a lo largo de mi formación en Ciencia de Datos utilizando un caso de estudio de una empresa de productos de consumo.

El objetivo fue analizar el comportamiento histórico de las ventas, identificar patrones y tendencias, segmentar productos y desarrollar modelos que permitieran explicar y pronosticar su comportamiento.

## Herramientas utilizadas

- Python
- Pandas y NumPy
- Matplotlib y Seaborn
- SQL Server
- Power BI
- Machine Learning
- K-Means
- Regresión Lineal Múltiple
- Modelos ARIMA

## Análisis realizados

A lo largo de las diferentes etapas del proyecto se realizaron:

- Limpieza y transformación de datos.
- Análisis exploratorio de datos (EDA).
- Análisis de ventas por marca, región, formato y segmento.
- Identificación y análisis de valores atípicos.
- Segmentación de productos mediante K-Means.
- Modelado mediante Regresión Lineal Múltiple.
- Análisis y pronóstico de series de tiempo mediante ARIMA.
- Consultas y análisis mediante SQL Server.
- Desarrollo de un dashboard interactivo en Power BI.

## Principales resultados

El análisis permitió identificar diferencias importantes en el desempeño de productos y regiones. Mediante K-Means se identificaron tres grupos de productos, destacando un grupo de alto desempeño compuesto por tres presentaciones de CLORALEX EL RENDIDOR, que concentraron aproximadamente el 26.67% del valor total de ventas analizado.

El modelo de Regresión Lineal Múltiple obtuvo un R² de 0.8311. Para el análisis de series de tiempo se utilizaron modelos ARIMA(0,1,2), obteniendo un MAPE aproximado de 11.49% para Vanish y 6.57% para Lysol.

Finalmente, los resultados fueron integrados en un dashboard interactivo desarrollado en Power BI para facilitar la exploración de ventas por marca, segmento, región y periodo.
